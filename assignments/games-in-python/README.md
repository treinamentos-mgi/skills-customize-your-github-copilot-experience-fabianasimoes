
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Preparar a palavra secreta e os palpites

#### Descrição
Use o código inicial para selecionar uma palavra secreta e permitir que o jogador tente adivinhá-la letra por letra.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras do usuário.
- Exibir o progresso da palavra oculta, mantendo visíveis as letras ainda não adivinhadas (por exemplo, `_ _ _ _`).
- Revelar no progresso todas as ocorrências de uma letra correta.

### 🛠️ Controlar as tentativas e encerrar o jogo

#### Descrição
Implemente o loop principal para atualizar o estado do jogo e informar o resultado ao jogador.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir o número de tentativas incorretas restantes.
- Continuar o jogo até que a palavra seja adivinhada ou as tentativas incorretas se esgotem.
- Exibir uma mensagem de vitória quando o jogador adivinhar a palavra.
- Exibir uma mensagem de derrota quando as tentativas se esgotarem.
